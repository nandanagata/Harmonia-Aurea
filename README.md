# Harmonia Áurea

Experimento audiovisual para a apresentação sobre o segmento áureo e a visita à Sala São Paulo.

## Saiba mais

Acesse a [documentação](./DOCUMENTACAO_DO_SITE.md)

## Recursos

- sintetizador com Web Audio API;
- sequência baseada em Fibonacci e em potências de Φ;
- sequência aleatória para comparação;
- visualizador responsivo;
- andamento e volume ajustáveis;
- explicação matemática e conexão com a Sala São Paulo;
- layout responsivo para computador e celular.
